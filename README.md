Spotify Tracks Data Analysis



Project Overview



This project analyzes a Spotify Tracks dataset containing 114,000 records using Python and Pandas. The main objective is to perform data transformation, handle missing values, generate meaningful insights, and visualize the results.



Dataset



\* Dataset: Spotify Tracks Dataset

\* Records: 114,000

\* Original columns: 21

\* Format: CSV



Technologies Used



\* Python

\* Pandas

\* Matplotlib

\* Seaborn

\* Google Colab



Tasks Performed



1\. Dataset reading using Pandas.

2\. Data exploration and understanding.

3\. Removal of unnecessary columns.

4\. Data transformation and creation of new columns.

5\. Null value identification and handling using mean imputation wherever applicable.

6\. Insight generation using grouping and sorting.

7\. Data visualization using different charts.

8\. Correlation analysis.



Key Finding



The correlation between danceability and popularity was found to be 0.035, indicating a very weak positive linear relationship.
